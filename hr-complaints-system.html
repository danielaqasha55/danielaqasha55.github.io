ARCHIVED — FOUNDATION PROJECT

HR Complaints System

Sistem pengurusan aduan yang menjadi asas (foundation) sebelum berkembang jadi Sistem Bantuan Teknikal yang lebih lengkap.

Laravel SQLite jQuery + Select2
Overview

Projek ni bermula sebagai sistem pengurusan aduan (complaint management) yang mudah — establishing core data model dan logic asas sebelum sistem berkembang jadi lebih kompleks dengan Change Request flow, role-switching, dan lain-lain fungsi lanjutan.

Data model asas

Struktur data teras yang dibina: Complaint, User, ComplaintPicStatus, dan jadual pivot complaint_assignees untuk sokong multi-assignee — di mana satu aduan boleh ditugaskan kepada lebih dari satu PIC.

Key features
  • Struktur tiga peranan asas: Staff, PIC, Admin
  • Fungsi multi-assignee untuk aduan yang perlu lebih dari satu orang tangani
  • Status flow: pending → in progress → resolved / not resolved
  • Integrasi Select2 untuk pemilihan staff/PIC yang lebih mesra pengguna
  • Man-hour tracking per PIC untuk setiap aduan
  • Penyelesaian isu foreign key constraint dalam SQLite semasa fasa awal
Evolusi projek

Sistem ni kemudiannya diperluas secara besar-besaran — ditambah jadual change_requests berasingan, flow approval CR penuh, role tambahan (SV, KB TM), dan dashboard analytics — akhirnya menjadi Sistem Bantuan Teknikal yang digunakan PKPP hari ini.
