AI Triage Agent

Eksperimen arkitektur AI agent untuk auto-triage dan auto-assign tiket Change Request & aduan dalam Sistem Bantuan Teknikal, menggunakan Anthropic API.

Laravel Queue Jobs Anthropic API Claude Sonnet
Overview

Idea di sebalik projek ni: bila tiket baru masuk ke Sistem Bantuan Teknikal, agent AI boleh automatik analyze kandungan tiket, cadangkan kategori/priority, dan sarankan PIC yang paling sesuai — dengan admin masih ada kuasa untuk override cadangan tersebut.

Arkitektur
1. Tiket baru dicipta → dispatch Laravel Queue Job
2. Job hantar stateless API call ke Anthropic API
3. Model (Claude Sonnet) pulangkan structured JSON output
4. Sistem simpan cadangan kategori/priority/PIC
5. Admin review & override jika perlu
Kenapa Queue Job?

Memandangkan API call ke Anthropic ambil masa dan tak sepatutnya block proses submit tiket, seluruh logic triage dijalankan secara asynchronous melalui Laravel Queue — pengguna terus dapat confirmation submit sementara AI analysis berjalan di latar belakang.

Status semasa

Masih di peringkat eksplorasi arkitektur — belum production-ready. Fokus semasa adalah design structured JSON output yang konsisten dan mekanisme admin override yang smooth.
