Sistem Bantuan Teknikal

Sistem helpdesk IT internal yang dibina dari kosong untuk PKPP (Perbadanan Kemajuan Pertanian Negeri Pahang), menggantikan proses aduan & permohonan Change Request yang sebelum ini manual.

Laravel MySQL Bootstrap 5 jQuery + Select2 Chart.js
Overview

Sistem ni dibina sebagai projek praktikal untuk jabatan IT PKPP — objektif utama adalah menggantikan proses aduan teknikal & permohonan Change Request (CR) yang tadinya manual, dengan satu sistem tersusun yang boleh track status, assign staff, dan generate laporan automatik.

Role & workflow

Sistem support role-switching penuh dalam satu akaun (guna Laravel session), membolehkan satu pengguna bertukar peranan mengikut keperluan:

Staff PIC Admin SV KB TM KB Dept lain
Key features
  • Flow approval Change Request penuh: Staff → KB Dept → auto-create complaint → Admin assign SV + KB TM → PIC resolve
  • Dashboard admin dengan doughnut chart (Chart.js) untuk overview status tiket
  • Man-hour tracking (jam + minit) per PIC untuk setiap tiket
  • Track page dengan pagination untuk gabungan complaint + Change Request
  • Email notification automatik untuk CR submission dan approval
  • Report PDF ringkasan bulanan untuk pihak pengurusan
  • Force Change Password middleware untuk keselamatan akaun baru
Challenges

Antara cabaran teknikal yang ditangani: menyelesaikan konflik constraint SQLite masa fasa awal development, memastikan role-switching tidak conflict dengan session state, dan struktur ulang data model bila skop Change Request diperluas jadi jadual berasingan dari complaint biasa.
